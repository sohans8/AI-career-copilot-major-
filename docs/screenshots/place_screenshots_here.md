# Screenshots Folder

Place your UI screenshots here.

## How to take a screenshot on Windows:
1. Open http://localhost:5173 in your browser
2. Press `Win + Shift + S`
3. Select the area you want to capture
4. Save the image as:
   - `dashboard.png` — Main assessment screen
   - `results.png`   — Results / recommendation screen
   - `streams.png`   — Stream catalog page
   - `careers.png`   — Career explorer page

These images are referenced in the main README.md via:
```markdown
![Dashboard](docs/screenshots/dashboard.png)
```
